## 📚 SAA-C03 Domains

- **[Domain 1: Design Resilient Architectures](./gemini_docs/01-resilient-architectures/)** — Multi-AZ/Multi-Region setups, Auto Scaling strategies, disaster recovery (RTO/RPO), and decoupled messaging (SQS, SNS).
- **[Domain 2: Design High-Performing Architectures](./gemini_docs/02-high-performing-architectures/)** — High-performance computing (HPC), caching layers (ElastiCache, DynamoDB Accelerator), database scaling (Aurora, RDS Read Replicas), and edge delivery (CloudFront).
- **[Domain 3: Design Secure Applications and Architectures](./gemini_docs/03-secure-architectures/)** — IAM least-privilege, KMS key policies, VPC security (NACLs vs. Security Groups), WAF, Shield, and GuardDuty.
- **[Domain 4: Design Cost-Optimized Architectures](./gemini_docs/04-cost-optimized-architectures/)** — Storage tiering (S3 lifecycle policies), EC2 pricing models (Spot, Reserved, Savings Plans), and cost visibility (AWS Budgets, Cost Explorer).
